# doggy-tasks

ワンコの世話を楽しく進めるためのシングルページTODOアプリです。フォームからタスクを登録し、フィルターやプログレスバーで進捗を眺めながら足あとチェックを入れられます。ブラウザのローカルストレージに保存されるので、リロードしてもデータが残ります。

## 使い方

1. `index.html` をブラウザで開きます（サーバー経由で開くとローカルストレージが有効になります）。
2. 上部フォームにタイトル・カテゴリー・たいせつ度・日付などを入力して「タスクを追加」をクリック。
3. リスト上で完了チェック、今日に設定、削除ができます。フィルターで「すべて / 予定 / 完了 / 今日 / たいせつ」を切り替えられます。
4. ローカルストレージを活用するので、データを初期化したいときはブラウザのストレージをクリアしてください。
